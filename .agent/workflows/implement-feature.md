# Implement Feature

## Steps

1. Read project rules.
2. Inspect existing architecture.
3. Find existing components that can be reused.
4. Read relevant requirements.
5. Read relevant design references.
6. Create an implementation plan.
7. Implement the smallest logical unit.
8. Run TypeScript checks.
9. Run lint.
10. Run tests.
11. Verify the UI.
12. Review the diff.
13. Report changed files.
14. Report remaining issues.
